# 🐾 GeoRadar CRM — Контроль парсинга гео-сервисов (Яндекс Карты & 2ГИС)

**GeoRadar CRM** — специализированный веб-инструмент для компаний, занимающихся регулярным сбором и парсингом лидов по городам и нишам (Яндекс Карты, 2ГИС).

Сервис исключает дублирование работы сотрудников, ведет единую базу поисковой активности, предоставляет наглядную аналитику и содержит готовый фундамент для полноценной B2B CRM панели.

---

## 🚀 Быстрый запуск в 1 клик

В папке проекта дважды кликните по файлу:
👉 **`start.bat`**

Скрипт автоматически:
1. Проверит установку библиотек из `requirements.txt`.
2. Инициализирует базу данных `data/georadar.db` с демонстрационными данными.
3. Запустит локальный сервер FastAPI.
4. Откроет интерфейс в вашем браузере по адресу: **`http://127.0.0.1:8000`**.

## 🎯 Основные возможности

### 1. ⚡ Радар дубликатов ("Проверка связки")
- Перед началом сбора сотрудник указывает **Город** (например, *Тюмень*) и **Нишу** (например, *Мебель*).
- **Мгновенный вердикт**:
  - 🚨 **Свежий дубль (< 60 дней)**: Маскот Радарчик кричит в мегафон! Система предупреждает, что связка уже спарсена, показывает дату сбора, кто парсил, сколько контактов собрано и заметки.
  - 🕒 **Парсилось давно (> 60 дней)**: База могла устареть, система рекомендует освежить контакты.
  - 🎉 **Чисто / Свободно**: Ниша свободна! В 1 клик можно нажать «Занять нишу в работу».

### 2. 📋 Журнал сборов и единая база данных
- Единый реестр всех операций: город, ниша, источник (Яндекс Карты, 2ГИС, оба), статус, количество собранных контактов, ответственный менеджер, дата и комментарии.
- Мгновенный поиск и умные фильтры.
- Экспорт всей базы или отфильтрованного среза в **Excel (.xlsx)** и **CSV**.

### 3. 📊 Аналитический дашборд
- Интерактивные диаграммы:
  - Баланс источников (Яндекс Карты vs 2ГИС).
  - Статусы задач (Завершено, В процессе, Требует обновления).
  - ТОП-8 городов по количеству собранных контактов.
  - ТОП-8 востребованных ниш.

### 4. 🐾 Интерактивный фирменный Маскот ("Радарчик")
- Создан по фирменному концепту (пушистый синий котёнок).
- Фирменная палитра: `#030E50`, `#1E3FB2`, `#2875FB`, `#C3D7FC`.
- Реагирует на действия сотрудников:
  - Предупреждает о дублях с мегафоном.
  - Танцует и радуется, когда ниша свободна или зафиксирован сбор.
  - Дает советы при клике на него (пасхалка).
  - Мягкие звуковые эффекты (можно включить/выключить иконкой звука в шапке).

## 🔌 Как подключить парсеры и скрипты (REST API)

Любой ваш Python-парсер, скрипт на Node.js или бот в Telegram может работать с GeoRadar напрямую через REST API:

### 1. Проверить связку перед парсингом:
```http
GET http://127.0.0.1:8000/api/check?city=Тюмень&niche=Мебель
```
Ответ возвращает флаг `is_duplicate: true/false`, статус `danger/warning/safe`, количество дней `days_since_last` и список совпадений.

### 2. Записать результат работы парсера:
```http
POST http://127.0.0.1:8000/api/parses
Content-Type: application/json

{
  "city": "Тюмень",
  "niche": "Мебель",
  "source": "2ГИС",
  "status": "Завершено",
  "records_count": 142,
  "operator_name": "Автопарсер",
  "notes": "Собрано 142 организации с мобильными номерами"
}
```

Интерактивная Swagger-документация API доступна по адресу:  
🔗 **`http://127.0.0.1:8000/docs`**

## 🗄️ База данных и резервное копирование

База данных хранится в одном файле:
📁 `data/georadar.db` (SQLite)

- **Как сделать бэкап:** просто скопируйте файл `georadar.db` в надежное место или на флешку / облако.
- **Как перенести на другой ПК:** скопируйте всю папку `GeoRadar-CRM` и запустите `start.bat`.

## 🧱 Фундамент под будущую CRM 2.0

В кодовой базе проекта (`app/models.py`) уже заложены ORM-модели для расширения:
- **`Company`**: хранение спарсенных организаций (название, телефон, сайт, email, рейтинг, количество отзывов).
- **`Lead`**: сущность лида для отдела продаж (статусы сделки: *Новый*, *Взят в работу*, *Звонок назначен*, *КП отправлено*, *Успех/Отказ*).

По мере развития вы сможете загружать спарсенные CSV/Excel файлы напрямую в карточки компаний и передавать их менеджерам по продажам.
